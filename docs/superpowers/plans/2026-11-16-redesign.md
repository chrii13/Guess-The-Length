# Redesign Guess the Length Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sostituire l'identità grafica con un sistema costruito attorno al metro, con animazioni legate a metro e numeri.

**Architecture:** Token come variabili CSS in `app/globals.css`, esposti a Tailwind 3 in `tailwind.config.ts`. Classi componente (`.btn`, `.campo`, `.cifre`) e keyframes in `globals.css`. Le pagine vengono riscritte nel markup lasciando intatti stato, effetti e chiamate a `lib/`.

**Tech Stack:** Next 14.0.4 (app router), React 18, Tailwind 3, `next/font/google` (Archivo), Jest (ambiente node).

**Spec:** `docs/superpowers/specs/2026-11-16-redesign-design.md`

## Global Constraints

- Nessuna dipendenza nuova.
- Nessuna modifica a `lib/`, `app/api/`, `components/AuthProvider.tsx`, né a stato/handler delle pagine oltre a quanto serve al markup.
- Colori solo dai token: `carta`, `foglio`, `inchiostro`, `grafite`, `riga`, `nastro`, `errore`, `acciaio`. Nessun esadecimale nelle pagine, nessuna classe `primary-*`.
- Ogni animazione è annullata sotto `prefers-reduced-motion: reduce`.
- Area di gioco senza griglie o righe regolari; tacche del metro irregolari come oggi.
- Niente commit: l'utente non li ha chiesti.

## Review Focus

- Metro più largo dello schermo su mobile (target fino a 8 cm): deve restare raggiungibile con lo scroll orizzontale come oggi.
- Tema scuro salvato in `localStorage`: nessun testo inchiostro su fondo inchiostro; il testo sul giallo resta sempre scuro.
- Username lunghi in classifica e navbar: troncati, non rompono la riga.
- Classifica e resoconto vuoti: stato vuoto con invito a giocare.
- `prefers-reduced-motion`: i numeri mostrano subito il valore finale.

Nessuno di questi è verificabile in Jest (ambiente node, niente DOM): vanno controllati nel browser nel Task 7.
